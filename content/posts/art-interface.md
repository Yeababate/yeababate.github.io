A browser-based tool for encoding and decoding text art. A Go server renders the interface, processes form input, and returns the result with clear validation feedback.

## What it does

A browser-based interface for encoding and decoding text art. Submit art or bracket notation, choose an action, and see the processed output. Invalid input is preserved for correction.

## Under the hood

Go handles form submissions and renders pages with html/template. Tailwind CSS styles the interface.
