A Go REST API for movies, actors, and genres, with SQLite persistence, filtering, pagination, and API-key authentication. Organized into handler, service, and repository layers.


## My contribution

I contributed across the project rather than focusing on a single component. The work spans a Go REST API backed by SQLite, with movie, actor, and genre management organized into handler, service, and repository layers.

## What it does

A REST API for managing movies, actors, genres, and their relationships. It supports CRUD operations, filtering, pagination, API-key authentication, and optional JSON seed data.

## Under the hood

Go’s standard HTTP server handles JSON requests and responses. SQLite stores the data, with handler, service, and repository layers separating responsibilities.
