Literary Lions Forum

A book discussion forum built with Go and SQLite. Readers can publish posts, reply to discussions, react to content, and find conversations through full-text search.

A book discussion forum built with Go and SQLite. Readers can publish posts, reply to discussions, react to content, and find conversations through full-text search.

What it does

Readers can create and edit posts, browse literary categories, comment and reply, react to discussions, and search using SQLite FTS5.

Under the hood

The Go backend separates HTTP handlers, services, repositories, middleware, and database access. Server-rendered templates provide the interface.
